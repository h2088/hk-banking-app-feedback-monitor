How to read this report

Sources, capture dates and coverage

Sentiment, topics and comment inclusion

The report is English; customer text and Apple titles remain verbatim. English, Traditional/Simplified Chinese, Cantonese writing and mixed comments all contribute to the same results. Request locale is not proof of comment language or reviewer location. Script/detector checks and documented exact-text decisions determine eligibility; uncertain or unsupported text is logged. Language metadata is retained for data quality only.

Rating sentiment: 1–2 stars negative, 3 neutral, 4–5 positive. This common proxy applies to all included comments. Eleven overlapping topics use English patterns and Traditional/Simplified/Cantonese terms; negation, irony and context can be missed. Broad terms can overmatch. Supplementary English lexicon fields in the detailed data are not the report's sentiment measure. Agent reading checks are not an independent human accuracy estimate.

Denominators and source verification

Every bank metric uses its combined English/Chinese reviews within one store. Monthly total volume sums the configured banks in that store; per-bank low-star shares use each bank's own monthly reviews. Theme shares divide by bank/store reviews. Empty monthly groups show N/A. Sample means are not store headline ratings.

Repeated IDs across locales count once. The first supplied observation wins for repeated IDs; alternate captures remain saved. Repeated wording under different IDs remains separate. Counts represent review records, not distinct customers.

Google links contain review IDs. Apple usually links to the app listing; verify title, body, rating and date there. Live reviews can change. Source text is checked against saved raw HTTP responses. No statistical significance, root cause, incident severity or customer-wide satisfaction is inferred.
