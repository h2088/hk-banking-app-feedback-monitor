# Checkpoint E - build and browser tests

The English report embeds only the English-window review payload, contains no external scripts/styles and displays exact customer text using safe text nodes. Store selection switches metrics, themes, monthly tables, examples and review results together. Other filters affect the review browser only, as labelled. Pagination is 25 records per page.

Verification evidence is in validation/static_results.json and validation/browser_results.json. The delivered report SHA-256 must match both. Screenshots are in screenshots/. A failed check is not completion; see checkpoint_F_final_review.md for the final gate.
